# Automated Test Refactoring

A Python-based tool for automated refactoring of Playwright test automation scripts.

The tool analyzes generated or existing Playwright tests and replaces repetitive code fragments with the best matching reusable methods from an existing automation framework.
## Features

- Test script analysis
- Cleanup and simplification of generated test scripts
- Matching and substitution of reusable framework methods
- Reduction of duplicated test code

## Tech Stack

- Python
- Playwright


## Installation and running script

```bash
pip install -r requirements.txt
python main.py
```
